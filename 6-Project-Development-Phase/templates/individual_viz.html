What This Visualization Shows:
{% if '2019' in title %}

This visualization displays electricity consumption data for all Indian states during the year 2019, allowing for state-by-state comparison and identification of consumption patterns.

{% elif '2020' in title %}

This visualization displays electricity consumption data for all Indian states during the year 2020, showing how consumption patterns changed compared to 2019 and the impact of COVID-19.

{% elif 'Total' in title %}

This visualization provides a comprehensive summary of total electricity consumption across all states and regions, with key statistics and aggregate metrics.

{% elif 'Region' in title %}

This visualization breaks down electricity consumption by geographical regions (North, South, East, West, Central), showing regional distribution and consumption patterns.

{% elif 'Top' in title %}

This visualization ranks states by electricity consumption, highlighting the top 10 highest consuming states and bottom 10 lowest consuming states for comparative analysis.

{% elif 'Month' in title %}

This visualization shows monthly consumption trends over time, revealing seasonal patterns, peak consumption periods, and year-over-year comparisons.

{% elif 'Heat' in title %}

This visualization uses a heat map to show consumption intensity across different regions and time periods, making it easy to identify consumption hotspots.

{% elif 'Lockdown' in title %}

This visualization compares electricity consumption before and after COVID-19 lockdowns, showing the impact of lockdown measures on energy usage patterns.

{% elif 'Map' in title %}

This visualization displays electricity consumption data on a geographic map of India, showing state-level consumption patterns with color-coded intensity.

{% elif 'Quarter' in title %}

This visualization breaks down consumption by quarters (Q1, Q2, Q3, Q4), showing seasonal patterns and quarterly variations in electricity usage.

{% elif 'Metro' in title %}

This visualization focuses on metropolitan cities, comparing consumption patterns between metro and non-metro areas and identifying urban consumption trends.

{% elif 'Year' in title %}

This visualization provides a year-over-year comparison of electricity consumption, showing trends and changes between 2019 and 2020.

{% else %}

This visualization provides detailed insights into electricity consumption patterns, supporting data-driven decision making and policy development.
