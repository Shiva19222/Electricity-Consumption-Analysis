Project Documentation

Complete documentation for the Electricity Consumption Analysis project

Project Overview

Plugging into the Future: An Exploration of Electricity Consumption Patterns Using Tableau is a comprehensive data visualization project that analyzes electricity consumption patterns across India from 2019-2020. This project leverages Tableau's powerful visualization capabilities to provide insights for utility companies, policymakers, and consumers.

Key Objectives:
  • Analyze time-of-day usage patterns across different regions and sectors
  • Examine seasonal variations and forecasting for better grid management
  • Provide sector-specific consumption insights for targeted conservation programs
  • Create professional visualizations and interactive dashboards
  • Develop a complete web application for project demonstration

Dataset Information

The project uses electricity consumption data scraped from weekly energy reports of POSOCO (Power System Operation Corporation Limited), covering a 24-month period from January 2019 to December 2020.

Dataset Details:
  • Records: 16,599 data points
  • States: 35 Indian states and union territories
  • Regions: 5 major regions (North, South, East, West, Central)
  • Time Period: January 2, 2019 to December 5, 2020
  • Fields: States, Regions, Latitude, Longitude, Dates, Usage
Enhanced Fields Added:
  • Year, Month, Quarter, Week of Year
  • Seasonal Classification (Summer, Winter, Monsoon)
  • COVID-19 Lockdown Analysis
  • Metro City Classification
  • Usage Categories and Levels
  • Day of Week Analysis

Visualizations Overview

The project includes 12 professional visualizations organized into three activities, each focusing on different aspects of electricity consumption analysis.

Activity 1.1 (5 Visualizations):
  • 2019 State Consumption
  • 2020 State Consumption
  • Total Consumption Summary
  • Usage by Region
  • Top N and Bottom N States
Activity 1.2 (3 Visualizations):
  • Month-wise Consumption Trends
  • Total Consumption Region Wise
  • Usage Before and After Lockdown
Activity 1.3 (4 Visualizations):
  • Region wise State Usage
  • Quarter Usage
  • Metro City State Usage
  • Usage by Year
