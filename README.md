# Electricity Consumption Analysis

A professional web-based dashboard for analyzing electricity consumption patterns across India using Tableau visualizations integrated with Flask web application.

## 🎯 Project Overview

This project analyzes electricity consumption data across 35 Indian states and 5 regions for the years 2019-2020, providing comprehensive insights through interactive visualizations and analysis scenarios.

## 📊 Dataset

- **16,599 records** of electricity consumption data
- **35 Indian states** across **5 regions**
- **Time period**: 2019-2020
- **Data points**: Monthly consumption by state and region

## 🚀 Getting Started

### Prerequisites
- Python 3.7+
- Tableau Desktop (for visualization creation)
- Git (for version control)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Shiva19222/Electricity-Consumption-Analysis.git
   cd Electricity-Consumption-Analysis
   ```

2. **Install Python dependencies**
   ```bash
   pip install flask
   pip install jinja2
   pip install markupsafe
   ```

3. **Run the application**
   ```bash
   python fixed_tableau_flask_app.py
   ```

4. **Access the application**
   Open your browser and go to: http://localhost:5000
